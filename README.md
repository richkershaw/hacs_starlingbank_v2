# Starling Bank Home Assistant Integration (v2)

This is a replacement for the official HASS component providing Starling Bank account data to Home Assistant. The currently shipped component uses (Adam Dullage's)[https://github.com/rahulpdev/starlingbank] PyPI package, which has not been updated since 2019, and was forked and updated with spending goal support by (rahulpdev)[https://github.com/rahulpdev/starlingbank], and then updated again by me to add support for fetching Space balances.

I built this replacement component to power pocket money monitoring dashboards for kids' savings.
